# Pretraining a Small Language Model from Scratch

CMPSC 448, Homework #3. This project trains a small GPT-style language model from scratch on the Sherlock Holmes stories by Arthur Conan Doyle, then lets you type prompts into it and watch what it writes.

The model starts with random weights (no pretrained weights) and learns only through next-token prediction on the text collected by `prepare_data.py`.

## Assignment steps

| Step | What the assignment asks | Where it happens |
|------|--------------------------|------------------|
| 1 | Find and download a text dataset from an online source | `prepare_data.py` |
| 2 | Choose a small model architecture and initialize it from scratch | `model.py` |

| `prepare_data.py` | Downloads the books from Project Gutenberg, strips the Gutenberg license header and footer, converts the text to plain ASCII, and writes `data.txt`. |

## Dataset

`prepare_data.py` downloads these books:

- A Study in Scarlet
- The Sign of the Four
- The Adventures of Sherlock Holmes
- The Memoirs of Sherlock Holmes
- The Hound of the Baskervilles
- The Return of Sherlock Holmes

Curly quotes and dashes are replaced with plain ASCII equivalents, and other non-ASCII characters are removed, so the character vocabulary stays small.

## Model

The model is a character-level GPT: every unique character in the dataset is one token.

| Setting | Value |
|---------|-------|
| Layers | 6 |
| Attention heads | 6 |
| Embedding size | 384 |
| Context length | 256 characters |
| Dropout | 0.2 |
| Parameters | about 10.8M (the exact count is printed by `train.py`) |

Training uses AdamW with a learning rate of 3e-4 and a batch size of 64 for 5,000 steps by default. The first 90% of the text is used for training and the last 10% for validation. Train and validation loss are printed every 500 steps.

## How to run

Requires Python 3 and [PyTorch](https://pytorch.org/get-started/locally/). A GPU is used automatically if one is available. Training on a CPU works but is much slower.

```bash
pip install torch
pip install truststore      # optional: helps downloads work behind antivirus or proxy HTTPS scanning

python prepare_data.py      # 1. download the dataset and write data.txt
python train.py             # 2-3. build the model and pretrain it, writes ckpt.pt
python chat.py              # 4. type prompts and see what the model generates
```

To check that everything works before a full run, train for a few steps only:

```bash
python train.py 200
```

## Prompting the model

`chat.py` asks for a prompt and continues it with 400 new characters. Press Enter with no prompt to let the model write from scratch, and press Ctrl+C to quit.

Generation settings are at the top of `chat.py`:

- `temperature = 0.8`: lower values give safer, more repetitive text, and higher values give more random text.
- `top_k = 40`: the model only samples from its 40 most likely next characters.

Example prompts to try:

- `Sherlock Holmes`
- `"My dear Watson,`
- `The hound`
- `I had called upon my friend`

Characters that never appear in the training data are dropped from the prompt.

Do not expect output like ChatGPT. A small character-level model trained for a few minutes usually learns spelling, punctuation, dialogue formatting, and character names, but its sentences often do not make sense.
